# Поиск перемещённых официальных правил

`parser/discover_official_sources.py` — небольшой обходчик официальных сайтов
вузов. Он не ищет по всему интернету и не использует ИИ: для каждого вуза
заранее задан стартовый URL и список разрешённых официальных хостов.

На ежедневном запуске он:

1. читает `robots.txt`, затем ограниченно обходит до 24 HTML-страниц глубиной
   до двух переходов и при наличии смотрит `sitemap.xml`. Ссылка на личный
   кабинет, ошибочная страница или временный ответ сайта пропускаются — один
   такой переход не останавливает весь обход;
2. ранжирует HTML, PDF и XLSX по понятным сигналам: год кампании, «правила
   приёма», «олимпиада», «РСОШ», «БВИ», «100 баллов», «особые права»;
3. сохраняет все найденные варианты, их балл, фрагмент ссылки и причины в
   `official_source_discovery_candidates`;
4. добавляет в `admission_source_targets` только ссылку с достаточными
   сигналами, которая находится на allow-listed хосте. На одну площадку
   активируется не больше восьми наиболее сильных новых источников за раз.

Вновь найденный документ разбирается только generic-парсером и создаёт
кандидаты на проверку. Он не может автоматически создать `benefit_rules`:
для публикации остаётся обязательной точная связь с площадкой, программой,
олимпиадой и документом приёмной кампании.

Локальная проверка без записи в PostgreSQL:

```bash
DATABASE_URL=postgresql://olimp:olimp@localhost:55432/olimp \
  python parser/discover_official_sources.py --force --dry-run --limit 7
```

Если вуз полностью меняет структуру сайта, достаточно изменить его seed URL
или allow-list в `configure_official_source_discovery_targets.py`; старые
снимки и проверенные льготы в базе не перезаписываются. Порог, глубина обхода
и лимит источников также задаются там явно для каждого вуза.
