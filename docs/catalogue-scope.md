# Что означает «все олимпиады» в Олимпе

Нельзя честно собрать «все олимпиады страны» одним парсером: условия, статусы
и даже само понятие олимпиады отличаются у РСОШ, регионов, вузов и студенческих
конкурсов. Поэтому каталог растёт по проверяемым официальным источникам.

Сейчас один запуск `parser/collect_olympiads.py` включает:

| Аудитория | Покрытие | Официальный источник |
| --- | --- | --- |
| Школьники | Все профили утверждённого Перечня РСОШ 2025/26 и их уровни, включая строки с объединённым названием олимпиады | `rsr-olymp.ru` |
| Студенты | Все опубликованные направления «Я — профессионал» текущего сезона | `yandex.ru/profi/courses` |

Новый источник добавляется отдельным адаптером только если он предоставляет
публичный каталог, отдельную официальную ссылку для каждой записи и понятную
дату/статус. Это не даёт смешать черновые анонсы с действующими олимпиадами.
