# Адаптеры каталогов программ вузов

Каталог программ и таблица льгот — это два разных источника. Таблица льгот
может говорить только про код направления `09.03.04`, а официальный каталог
называет одну или несколько программ внутри него. Поэтому в «Олимпе» они
обновляются независимыми контурами.

```text
официальный каталог конкретной площадки
  → adapter_code конкретного вуза
  → university_catalogue_parse_runs
  → university_programs (named_verified)

официальное приложение о льготах
  → strict admission adapter
  → benefit_rules (code_only или точная программа)
```

`code_only` не заменяется автоматически красивым названием из каталога:
внутри одного направления может быть несколько программ. Так сохраняется
точная связь льготы с тем объёмом, который указан в документе приёмной
кампании.

## Текущие адаптеры

| Адаптер | Формат | Привязанный официальный источник |
| --- | --- | --- |
| `catalogue-hse-2026-v1` | HTML-каталог/таблица | НИУ ВШЭ, Москва |
| `catalogue-mipt-2026-v1` | HTML-таблица конкурсных групп | МФТИ, Долгопрудный |
| `catalogue-mephi-2026-v1` | HTML-таблица «код → направление → программа» | НИЯУ МИФИ, Москва |
| `catalogue-msu-2026-v1` | PDF КЦП | МГУ, Москва |
| `catalogue-bmstu-2026-v1` | HTML-таблица КЦП | Калужский филиал МГТУ им. Н. Э. Баумана |
| `catalogue-mai-2026-v1` | HTML-карточки программ | МАИ, Москва |
| `catalogue-mirea-2026-v1` | HTML-реестр программ | Филиал РТУ МИРЭА, Ставрополь |

У Бауманки и МИРЭА в конфигурацию добавлены только филиальные источники,
которые действительно описывают филиал. Они намеренно не используются для
Москвы. Для нового кампуса нужно добавить новую строку в
`configure_university_catalogue_targets.py`, а не копировать чужой каталог.

## Ежедневный запуск

`admission-crawler` выполняет следующие шаги раз в сутки:

1. Загружает перечень площадок.
2. Привязывает проверенные источники каталогов к площадкам.
3. Запускает `crawl_university_catalogues.py`.
4. Обновляет таблицы льгот и экспортирует публичные JSON-снимки.

Если адаптер вернул ноль программ, запуск отмечается ошибкой, а прежний
подтверждённый каталог остаётся видимым. Ничего не удаляется по одному
неудачному проходу.
